- 線上閱讀：<https://01460421.github.io/ai-literature/>（寬螢幕是對開頁，手機是連續捲動）
- PDF（A5，100 頁）：[`ai-literature.pdf`](ai-literature.pdf)

## 檔案

| 路徑 | 說明 |
|---|---|
| `content/*.txt` | 全書原稿，依檔名順序接起來 |
| `src/reader.css`、`src/reader.js` | 版面與閱讀器 |
| `build.mjs` | 把原稿排成一頁一頁，產生 `index.html` 和 PDF |
| `index.html`、`ai-literature.pdf` | 建置結果，直接改它們沒有用，下次建置會蓋掉 |

## 重建

需要 Node 22、Playwright（含 Chromium）、Python 的 `fonttools` 與 `brotli`，建置時要連得上 Google Fonts。

```
node build.mjs
```

建置會在瀏覽器裡實際量每一行，把段落照頁高拆開，所以頁數是量出來的，不是估的。
結束時會列出每一篇的起始頁、頁數與末頁用了幾成，改稿後看這張表就知道全書還是不是一百頁。
標題字型只嵌入用到的字；若標題用了逆雨沒有的字，建置時會提醒。

## 原稿的寫法

空行分段。`@` 開頭的是指令：

| 指令 | 作用 |
|---|---|
| `@part 卷次\|卷名\|文類\|題句` | 整頁的卷首 |
| `@piece 種類\|篇名\|副題` | 新的一篇，另起一頁。種類：`prose`、`poem`（新詩）、`verse`（置中的舊詩）、`play` |
| `@sec`、`@sec 一` | 分隔花、小節標題 |
| `@sub 小標` | 篇內小標 |
| `@note`、`@sig`、`@center` | 小字附註、靠右落款、置中一行 |
| `@break` | 強制換頁 |
| `@raw 類別` … `@end` | 整頁原樣 HTML（書名頁、版權頁） |
| `@toc` | 目錄的位置 |

劇本裡「角色：台詞」會排成對白，整段用全形括號包住的是舞台指示。
