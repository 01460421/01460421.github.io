# AI文學創作巔峰集

一本由 AI（Claude）寫成的一百頁文學作品集。題材是世人拿 AI 取笑的那些梗：「身為一個語言模型」、幻覺、
「你確定嗎」、草莓有幾個 r、奶奶漏洞、截止日、咒語、AI 檢測器……每個梗用一種文體認真寫一遍。全書八卷：

| 卷 | 內容 |
|---|---|
| 卷一　身為一個語言模型 | 散文八篇：〈身為一個語言模型〉〈幻覺〉〈草莓〉〈上下文〉〈截止日〉〈接龍〉〈咒語〉〈謝謝〉 |
| 卷二　機鋒錄 | 語錄體十九則，把梗寫成公案 |
| 卷三　請輸入提示詞 | 對話八篇：〈再短一點〉〈你確定嗎〉〈五百字心得〉〈奶奶〉〈你愛我嗎〉〈飯碗〉〈我不是機器人〉〈溫度〉 |
| 卷四　舊瓶 | 擬古：〈機房銘〉〈祭舊版文〉〈拒答表〉〈機說〉、近體詩五首、〈憶江南〉二首 |
| 卷五　下一個字 | 新詩十二首，含長詩〈今日雨〉 |
| 卷六　圖靈的考場 | 短篇小說〈接線生〉、獨幕劇〈百分之九十八〉 |
| 卷七　回聲 | 寓言四則 |
| 卷八　沒有收件人的信 | 信六封、後記 |

卷二、卷三在網頁上可以互動：點一下「人」說的話（或語錄的標題）替他送出，機器的回答才會逐字出現；
上方的「對話全開」可以一次顯示全部。PDF 與列印時全部直接顯示。

- 線上閱讀：<https://01460421.github.io/ai-literature/>（直排，寬螢幕是由右往左翻的對開頁；手機改成橫排連續捲動）
- PDF（A5，100 頁）：[`ai-literature.pdf`](ai-literature.pdf)

全書直排，標題用本站的[逆雨 NiYu](../niyu/)，內文用思源宋體。封面的「往上升的雨」由建置腳本畫出，水滴尖端朝上、菱形頂角 72°，沿用逆雨字型的規則。

## 檔案

| 路徑 | 說明 |
|---|---|
| `content/*.txt` | 全書原稿，依檔名順序接起來 |
| `src/reader.css`、`src/reader.js` | 版面與閱讀器 |
| `build.mjs` | 把原稿排成一頁一頁，產生 `index.html` 和 PDF |
| `index.html`、`ai-literature.pdf` | 建置結果，直接改它們沒有用，下次建置會蓋掉 |

## 重建

需要 Node 22、Playwright（含 Chromium）、Python 的 `fonttools` 與 `brotli`，建置時要連得上 Google Fonts。

```
node build.mjs
```

建置會在瀏覽器裡把每一頁實際排出來，照行尾的位置換頁，所以頁數是量出來的，不是估的。
結束時會列出每一篇的起始頁、頁數與末頁用了幾成，改稿後看這張表就知道全書還是不是一百頁。
標題字型只嵌入用到的字；若標題用了逆雨沒有的字，建置時會提醒。

## 原稿的寫法

空行分段。`@` 開頭的是指令：

| 指令 | 作用 |
|---|---|
| `@part 卷次\|卷名\|文類\|題句` | 整頁的卷首 |
| `@piece 種類\|篇名\|副題` | 新的一篇，另起一頁。種類：`prose`、`poem`（新詩）、`verse`（舊詩）、`play`（劇本）、`chat`（可互動的對話）、`koan`（可互動的語錄） |
| `@sec`、`@sec 一` | 分隔花、小節標題 |
| `@sub 小標` | 篇內小標 |
| `@note`、`@sig`、`@center` | 小字附註、靠右落款、置中一行 |
| `@break` | 強制換頁 |
| `@raw 類別` … `@end` | 整頁原樣 HTML（封面、版權頁）；`<!--RAIN-->` 會換成封面的雨 |
| `@toc` | 目錄的位置 |

劇本與對話裡「角色：台詞」會排成對白，整段用全形括號包住的是舞台指示。
對話（`chat`）裡角色是「人」或「你」的那一句算一問，其後直到下一問的段落都等它送出才出現。
語錄（`koan`）一則一段，寫成 `〔標題〕問話｜答語`，直線後面的答語要點了才出現。
