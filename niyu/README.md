# 逆雨 NiYu

一套原創的觀賞型（展示用）襯線字型，含拉丁字母、數字、標點、重音字與 **5,383 個常用中文字**，
共 5,745 個字符、5,621 個碼位。依照「逆雨」字型製作流程從零做出。

- 線上樣張：<https://01460421.github.io/niyu/>（分支合併後生效）
- 字型檔：[`../fonts/`](../fonts/)
  - `NiYu-Regular.otf` / `.ttf` / `.woff2`：完整字集（含中文）
  - `NiYu-Regular-Latin.woff2`：只含拉丁字母的網頁子集（22 KB）
- 拉丁部分可續修的原始檔：[`sources/NiYu-Regular.ufo`](sources/)
- 授權：SIL Open Font License 1.1（[`../fonts/OFL.txt`](../fonts/OFL.txt)）

拉丁字母、數字與符號全部由 `src/` 裡的程式以參數畫成，沒有描摹任何現成字型或標誌的輪廓。
中文字以 Noto Serif TC（思源宋體的 Google 版，OFL 授權）為底，逐筆套用同樣的三條規則改作；
依 OFL 的要求，衍生字型已改名並維持 OFL。

## 三條規則

| 特徵 | 規則 | 拉丁字母 | 中文 |
|---|---|---|---|
| 逆雨滴 | 水滴形終端的尖端永遠朝上；只有大、小兩種尺寸 | a c f g j r s y、C G J S、2 3 5 6 9、? & $ £ € | 朝上的鉤（豎鉤、豎彎鉤、斜鉤、臥鉤）末端升起一滴雨 |
| 斷線 | 細筆接粗筆處留一道縫（拉丁 16、中文 14 單位） | n m h r u、a b d p q k、A B D E F H K P R | 橫畫在碰到粗筆的地方停住；穿過去的橫畫不切 |
| 菱形點 | 所有的「點」改用頂角 72° 的菱形 | i j . : ; ! ? … ÷ 與分音符；A E F H 橫畫上的菱形結 | 所有的點 |

**雨字頭的例外**：雨、雪、雲、電、霧、露、霜、靈……這些字裡的點不是菱形，而是向上升的雨滴。
整套字的名字就是從這裡來的。

隱形規則：所有斜切的筆端共用 18°。18° 是五芒星尖角（36°）的一半，菱形點的頂角是它的四倍（72°）。

每個字符最多背兩個特徵（例如 a＝雨滴＋斷線，H＝斷線＋菱形結，j＝雨滴＋菱形點）。

### 觀賞型的設定

這一版比第一版更往「觀賞」靠：

- 粗細對比加大：直筆 92／102，髮絲 22／24。
- 大寫也有雨滴（C G J S），小寫 s、g 加上雨滴。
- 斷線擴及 a b d p q k 與 A E F H K，A E F H 的橫畫浮在兩筆之間，中間有一顆菱形結。
- **花飾預設開啟**（`calt`）：字首的 A M N 向左甩出一滴雨，K L Q R 的長尾掃過字底，字尾的 y 拖長尾。
  花飾只在有空間時出現，遇到降部字母會自動讓開。想要安靜一點：`font-feature-settings: "calt" 0`。

## 中文是怎麼做的

Noto Serif TC 的可變字型把每一筆留成獨立、互相重疊的輪廓，所以規則可以逐筆套用，而不是對整個字的外形硬改：

1. 取 wght 560 的實例（豎筆約 94 單位，與拉丁直筆相稱）。
2. 把每個輪廓分類：細橫、點、其他粗筆。
3. **菱形點**：點換成同樣大小的菱形；雨字頭（U+96E8–U+9750）換成上升的雨滴。
4. **斷線**：細橫的端點若落在粗筆上，就在粗筆外緣留一道縫；橫畫整條穿過粗筆（例如「重」的中豎）則不切，免得把字切成兩半。
5. **逆雨滴**：在粗筆上找朝上的尖鉤（很細的尖端、附近有一個凹角、位在筆畫下半段），放上一滴尖端朝上的雨；若會撞到別的筆畫就不放。
6. 每個字做完後檢查墨量與外框，變化過大的字退回底字原樣。

字集是 Big5 第一字面（常用字 5,401 字）中底字有收的 5,383 字。統計：5,382 字套用了規則、1 字因變化過大退回底字原樣；共重畫 15,087 個點、為 13,585 條橫畫留縫、在 1,963 個鉤上放了雨滴。

## 重建

```bash
pip install fonttools brotli skia-pathops ufoLib2
python niyu/build.py            # 全部重建（第一次會用 npm 下載 5.9 MB 的底字，並花幾分鐘處理中文）
python niyu/build.py --fast     # 略過 UFO
python niyu/build.py --no-cjk   # 只建拉丁部分，幾秒完成

pip install fontbakery
fontbakery check-universal fonts/NiYu-Regular.ttf
```

中文的處理結果會快取在 `niyu/.cache/`（不進版本庫）；`src/cjk.py` 或相關參數一改就會重算。
