# 逆雨 NiYu

一套原創的展示用襯線字型：拉丁字母、數字、標點、重音字，共 335 個字符、211 個碼位。
依照「逆雨」字型製作流程從零做出，整套字由程式畫成，沒有描摹任何現成字型或標誌的輪廓。

- 線上樣張：<https://01460421.github.io/niyu/>（分支合併後生效）
- 字型檔：[`../fonts/`](../fonts/)（OTF、TTF、WOFF2）
- 可續修的原始檔：[`sources/NiYu-Regular.ufo`](sources/)（Fontra、FontForge、Glyphs 都能開）
- 授權：SIL Open Font License 1.1（[`../fonts/OFL.txt`](../fonts/OFL.txt)）

## 三條規則

| 特徵 | 規則 | 套用字符 | 不套用 |
|---|---|---|---|
| 逆雨滴 | 水滴形終端的尖端永遠朝上；只有大、小兩種尺寸 | a c f j r y、2 3 5 6 9 | 大寫字母（預設層） |
| 斷線 | 細筆接粗筆處留一道 12 單位的縫 | n m h r u、B P R D | a e s |
| 菱形點 | 所有的「點」改用頂角 72° 的菱形 | i j . : ; ! ? … ÷ 與分音符 | 逗號、引號 |

頂部終端的雨滴懸在髮絲線下方；底部終端（j y 3 5 9）的雨滴坐在筆畫末端，尖端自由地朝上，
這是流程文件裡「底部終端比較難處理」那一題的解法。

隱形規則：所有斜切的筆端共用 18°。18° 是五芒星尖角（36°）的一半，菱形點的頂角是它的四倍（72°）。

### 兩層設計

- **第一層（預設）**：守住閱讀，只帶上面三個特徵。
- **第二層（`ss01`）**：花飾大寫 A K L M N Q R Y 與長尾 y。大寫在這一層才有雨滴：長尾掃過字底，以升起的雨滴收尾。

## OpenType 功能

| 功能 | 內容 |
|---|---|
| `liga` | fi、fl、ff。fi 裡 f 懸垂的雨滴取代 i 的點 |
| `smcp` / `c2sc` | 小型大寫（含重音字），與大寫共用同一份繪製程式 |
| `onum` / `lnum` | 舊式數字 / 等高數字（預設） |
| `tnum` / `pnum` | 等寬數字（600 單位）/ 比例數字（預設） |
| `zero` | 中心帶菱形的零 |
| `case` | 全大寫時把連字號、括號等標點抬高 |
| `ss01` | 花飾大寫與長尾 |
| `kern` | 以群組為單位的字偶間距，約 11,000 組群組配對 |

另有一組細線幾何符號：◆ ◇ ○ ◎ △ ▽ ☆ ⛤ ✦ ✧ † ‡ ❧ 與分隔線 ⸻。

## 重建

```bash
pip install fonttools brotli skia-pathops ufoLib2
python niyu/build.py          # 輸出 fonts/ 的 OTF、TTF、WOFF2 與 sources/ 的 UFO
python niyu/build.py --fast   # 略過 UFO，改字形時用

pip install fontbakery
fontbakery check-universal fonts/NiYu-Regular.ttf
```
