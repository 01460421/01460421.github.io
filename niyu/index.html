逆雨Rain, rising.

1929196619871999

骨架保守，細節放肆。雨滴一律朝天，細筆在碰到粗筆之前留一道縫，所有的點都是菱形。同樣三條規則，從拉丁字母一路套到五千多個中文字。

幾何與參數

18° 從五芒星來

五芒星的尖角是 36°，取一半就是全套字共用的斜切角 18°；取兩倍就是菱形點的 72°。所有斜切的筆端都用這個角度，所以整套字看起來是一家人。

使用

檔案與語法

網頁

/* 拉丁子集先載入，用到中文才抓完整檔 */
@font-face {
  font-family: "NiYu";
  src: url("/fonts/NiYu-Regular-Latin.woff2") format("woff2");
  unicode-range: U+0000-024F, U+2000-22FF, U+25A0-27BF;
  font-display: swap;
}
@font-face {
  font-family: "NiYu";
  src: url("/fonts/NiYu-Regular.woff2") format("woff2");
  unicode-range: U+3000-303F, U+4E00-9FFF, U+FF00-FFEF;
  font-display: swap;
}
h1 { font-family: "NiYu", serif; }
/* 關掉花飾 */
.quiet { font-feature-settings: "calt" 0; }

  Path = ./fonts/,
